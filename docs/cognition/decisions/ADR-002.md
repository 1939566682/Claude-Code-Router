# ADR-002 — Codex 日志 `requestId` 归一：`turnKey` 不得当 `requestId`

- **日期**：2026-10-19
- **状态**：已采纳（`bf35654` 已推）
- **相关**：`packages/core/src/observability/raw-trace-sync.ts:1650`、`CHANGELOG:v1-1`

## 背景

`raw-trace-sync.ts` 曾 `requestId = x-client-request-id || turnKey || bundleId`，而 Codex 同会话的 `turnKey` 复用、`bundleId` 每请求唯一，`request-log-store` 的 `UPDATE WHERE requestId=turnKey` 把同会话 N 个 bundle 坍缩为 1 行（会话 `01a14ad1` 70 bundle→1 行）。

## 决策

`requestId = clientReqId!==turnKey ? clientReqId : bundleId`（`bf35654`）。会话级 `turnKey` 不再冒充请求级 `requestId`，`N bundle→N 行`。

## 后果

- 正：`request-logs` 与 `usage` 对齐，7 天视图不再丢柱。
- 负：历史 `turnKey` 写入的行需迁移或重放，不影响新写。

## 替代

- `turnKey+bundleId` 复合键：需改表结构与查询，成本高。
- 保留 `turnKey` 仅作展示字段：已隐含采纳（`turnKey` 仍存但不参与 `requestId` 归一）。

# ADR-003 — 中间件多字节/丢帧/标点：修实现不删功能

- **日期**：2026-10-19
- **状态**：已采纳（`39810e9` 已推）
- **相关**：`packages/core/src/agents/codex/cli-middleware-runtime.ts`、`CHANGELOG:v1-2`

## 背景

`96ece438` 引入 `StringDecoder + pending尾刷 + 补句号` 好功能，但带 3 个回归：`runOpenCodeBotCli` 丢 `let pendingJson`（`ReferenceError`）、`String.raw` 模板里 `/\r?\n/g` 被写成 `/\n?\n/g`（`\r` 残留致 `JSON.parse` 失败）、标点 `/[。？！]$/` 误伤英文/代码。

## 决策

`39810e9` 回炉修实现不删功能：
- 补 `let pendingJson=""`（2 处）、3 处 `/\n?\n/g→/\r?\n/g`、`StringDecoder("utf8")+decoder.end()` 冲刷保留；
- `if(elapsed<700) return` → `pending+setTimeout(flush)` 尾刷不丢帧；
- `/[。？！]$/→/[。？！.!?]$/`。

## 后果

- 正：多字节不 `�`、中间帧不丢、英文/代码不误加 `。`。
- 负：仍保留“补 `。`”逻辑，属为过检验而改数据；更干净的做法是改校验器而非改输出，待后续 ADR。

## 替代

- 整体回退到官方 `057abaa1`：删功能，最稳但丢修复价值，不采纳。
- 改校验器不改数据：更正，已记为后续优化方向。
